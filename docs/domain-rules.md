# 领域规则

现行业务语义的唯一正文；其他合同仅补对应维度，归属见 [合同索引](contracts-index.md)。实现限制如实保留，不把期望能力写成既成事实。

## 模型状态

`NOT_INSTALLED -> DOWNLOADING -> VERIFYING -> READY`

异常可进入 `PAUSED`、`FAILED` 或 `CORRUPT`。只有模型文件、清单和校验记录一致时才能进入 `READY`。发现损坏后必须阻止加载，并提供重新下载或重新导入路径。

## 模型长期缓存

- 下载写入 `.part`，保留已下载字节用于续传。
- 完成后校验声明长度与 SHA-256，再以原子移动提交为正式模型。
- 启动时做快速一致性检查；下载完成、发现可疑状态、用户手动验证时做完整哈希。
- 进程退出、重启、同签名覆盖升级不得清除模型。
- 导出和导入都走 Android SAF；导入后执行与下载相同的完整校验。
- 下载服务器支持 Range 时从 `.part` 续传；服务器忽略 Range 时从零重写临时文件，不能把完整响应追加到旧字节后。
- 下载、导入、导出由同一个 `ModelAssetManager` 串行协调；正式模型文件只允许 `FileModelStore` 原子提交。

## 转写任务

`QUEUED -> PREPARING -> TRANSCRIBING -> EXPORTING -> COMPLETED`

输入/模型不足进入 `WAITING_INPUT` / `WAITING_MODEL`，失败进入 `FAILED`，用户停止进入 `CANCELLED`；不是可任意暂停的执行模式。无可读文字进入 `NO_SPEECH`，留在主页允许重试。进程中断后进入 `RECOVERY_REQUIRED`，不伪装为完成。持久状态以 `TranscriptionTaskState` 为准。

- 字幕探测是 `PREPARING` 内部阶段，不是独立 Room 状态；不依赖本地语音模型，有可读文字轨时直接产生分段和时间轴。
- 只有无字幕、字幕不可读或字幕为画面像素时才进入语音模型检查。模型未安装必须转为可恢复的等待模型，不得在 UI 入口预先丢弃这条任务。

## 队列和会话

- 默认保持用户队列顺序，不隐式重排。
- 相邻任务仅在 provider、模型真实路径和有效线程数匹配时复用队列级会话；provider或线程变化会重建引擎，模型路径变化由 ModelSessionManager 释放并重新加载。不同任务目录的云端session路径不同，不能承诺跨文件复用同一个远端任务。
- 如提供“按模型优化队列”，必须由用户显式开启并展示排序影响。
- 用户取消当前任务会停止本轮队列，不自动开始下一项；单项失败由队列继续查询下一条排队任务，不能将“取消”和“失败”混为停止所有任务。

## 后台执行与呈现

- Room v7 是跨进程任务真相；`TranscriptionForegroundService` 在独立进程执行，`BackgroundTranscriptionQueue` 的 finally 统一释放资源。
- 只对已完成并提交的音频片段计算转写进度；字幕、解码、加载、转写、保存是不同阶段。比例达到结尾也不在私有结果和完成状态提交前显示 100%。
- 通知与悬浮窗共用 `NanfengIslandState`；用户取消后晚到进度不得覆盖取消状态，展示失败不应中断 ASR。
- SenseVoice 当前推荐分块为 30 秒，断点在片段提交后保存；不能沿用旧版固定 5 分钟的描述或承诺恢复所有尚未提交的计算。
- partial wake lock 使用有界租约并在执行期间续期；系统强制停止、关机、OEM 管控或前台服务时限仍可能中断，重开后的已保存断点恢复不等于永不被杀。
- 系统进程 importance 包含前台服务与绑定影响，不能直接把高重要性推导成可见 Activity；悬浮窗不能影响主流程，未授权回退通知。

## 输出

- 首发输出 `TXT`、`Markdown`、`SRT`、`DOCX`。
- 用户可在设置中固定同名文件策略：自动重命名、覆盖或跳过；默认自动重命名，不能无策略静默覆盖。
- App私有结果按taskId分目录；用户明确导出时直接写入所选SAF目录，不额外创建媒体子目录。外部文件名清理非法字符并限制长度，冲突由重命名/覆盖/跳过策略决定。
- 转写完成先由 TranscriptDocumentStore 提交 App 私有 JSON 真相，再由 runner 写入 TXT 便捷副本，二者成功后才归档历史；JSON 使用临时替换，TXT 当前为直接输出流，不能声称二者同属一个原子事务。绝不因已设置输出目录而自动向用户目录写入文件。
- 用户仅在结果页明确点按“导出”后，才向设置的 SAF 默认目录写入所选格式；外部目录导出失败不得丢失历史结果。
- 每次任务只使用一个已选转写模型，不再执行转写后文字润色。
- SenseVoice/Whisper 在本机处理音视频；新高精度 Qwen Audio 3.1 Filetrans 与低成本 Paraformer-v2 沿用既有百炼 API Key，经百炼临时上传直接转写音频分段，用户选择云端模型并开始任务才外发，设置注明最长 48 小时临时保留和潜在费用。旧 Qwen3-ASR 只保留已创建任务的协议兼容，不再作为新模式展示。
- 千问 API Key 只保存在 Android Keystore 加密后的专用 SharedPreferences 中，不进入 DataStore、Room、日志、Git 或备份；服务地址和模型名不向用户开放编辑。
- Qwen 的 401/403、超时、限流、空响应和格式异常均转为中文原因；不得把 API 故障伪装为本地转写完成。
- 无语音、格式不支持、权限失效、模型损坏等均显示中文原因和下一步。

## 实现边界与兼容语义

- 字幕探测之前先验证原文件可读和任务模型版本；云端模式还先检查Key密文是否存在。因此“字幕无需本地模型”不等于“云端无Key也可直接提取”。密文存在不代表可解密或账号有效，真实请求失败仍按原因处理。
- 历史搜索只匹配文件名和historyPreviews短摘要，不是全文索引；常规预览最多读360字符并压缩为120字符。结果JSON打开仍在IO读取，不承诺零加载。
- 正文编辑只更新ViewModel内存草稿，当前不写回transcript.json；复制与TXT/MD/DOCX导出使用草稿，SRT保留原分段时间轴。没有跨进程/重启的编辑持久化保证。
- 默认目录SKIP命中已有文件时返回Skipped，不写新字节；当前UI统一显示“已保存到默认输出目录”，不能据该文案推断发生新写入。外部导出不与私有JSON/Room组成一个事务。
- 文件选择只在当前输入/待选集合按URI或PendingSource.key去重，没有跨Room任务与历史的全库内容哈希去重；不能声称所有重复文件自动跳过。
- 云端取消仅中止本地工作/请求，没有服务端取消接口；远端可能继续并产生费用。提交状态不明时拒绝自动重提，已持久化远端ID则读取同一任务。
- 新设置旧Qwen选择可解析为新模式；已创建旧Qwen任务仍保留原协议。Whisper和旧文字后处理保留内部研发/兼容代码，不构成当前公开模型入口或运行时润色能力。
- JSON/断点/模型提交在文件系统不支持ATOMIC_MOVE时退回普通替换；失败后不能宣称跨文件/数据库事务或所有存储的断电原子性。

这些边界对应 ViewModel、HistoryScreen、AndroidTranscriptOutputStore、runner、QueueModelSessionOwner、DashScopeFileTranscriptionEngine；具体源码入口由 [架构治理](architecture-governance.md) 维护，验证不足项由 [状态](PROJECT_STATUS.md) 维护。
