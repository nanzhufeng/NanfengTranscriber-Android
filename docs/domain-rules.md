# 领域规则

## 模型状态

`NOT_INSTALLED -> DOWNLOADING -> VERIFYING -> READY`

异常可进入 `PAUSED`、`FAILED` 或 `CORRUPT`。只有模型文件、清单和校验记录一致时才能进入 `READY`。发现损坏后必须阻止加载，并提供重新下载或重新导入路径。

## 模型长期缓存

- 下载写入 `.part`，保留已下载字节用于续传。
- 完成后校验声明长度与 SHA-256，再以原子移动提交为正式模型。
- 启动时做快速一致性检查；下载完成、发现可疑状态、用户手动验证时做完整哈希。
- 进程退出、重启、同签名覆盖升级不得清除模型。
- 导出和导入都走 Android SAF；导入后执行与下载相同的完整校验。
- 下载服务器支持 Range 时从 `.part` 续传；服务器忽略 Range 时从零重写临时文件，不能把完整响应追加到旧字节后。
- 下载、导入、导出由同一个 `ModelAssetManager` 串行协调；正式模型文件只允许 `FileModelStore` 原子提交。

## 转写任务

`QUEUED -> PREPARING -> SUBTITLE_PROBE -> TRANSCRIBING -> EXPORTING -> COMPLETED`

任务可暂停在等待输入/模型，失败进入 `FAILED`，用户停止进入 `CANCELLED`。转写完成但没有可读文字时进入 `NO_SPEECH`，继续留在主页并允许重试，绝不能伪装成已完成历史。应用进程死亡后，运行态任务恢复为可诊断的等待恢复状态，不能伪装为完成。

- `SUBTITLE_PROBE` 不依赖本地语音模型；有可读内嵌文字轨时直接产生分段和时间轴。
- 只有无字幕、字幕不可读或字幕为画面像素时才进入语音模型检查。模型未安装必须转为可恢复的等待模型，不得在 UI 入口预先丢弃这条任务。

## 队列和会话

- 默认保持用户队列顺序，不隐式重排。
- 相邻任务使用同一模型且线程配置相同时复用同一个队列级内存会话；切换模型或线程时才释放并重建。
- 如提供“按模型优化队列”，必须由用户显式开启并展示排序影响。
- 停止当前任务后不自动开始下一项，保持 Windows 版行为。

## 输出

- 首发输出 `TXT`、`Markdown`、`SRT`、`DOCX`。
- 用户可在设置中固定同名文件策略：自动重命名、覆盖或跳过；默认自动重命名，不能无策略静默覆盖。
- 每个媒体建立独立结果目录，文件名必须清理非法字符并限制长度。
- 先原子保存 App 私有 JSON/TXT 真相文件，再向用户选定的 SAF 目录自动导出；外部目录导出失败不得丢失历史结果。
- 本地原始结果先安全落盘，再执行可选兼容文本 API 润色。
- 翻译润色默认关闭；只有任务显式冻结为开启时才发送转写文字，音视频本体永不上传。
- API Key 只保存在 Android Keystore 加密后的专用 SharedPreferences 中，不进入 DataStore、Room、日志、Git 或备份；接口地址和模型名可由用户自填。
- 兼容服务必须使用 HTTPS。401/403、超时、限流、空响应和格式异常均转为中文原因；任何失败都以原始转写继续完成。
- 无语音、格式不支持、权限失效、模型损坏等均显示中文原因和下一步。
