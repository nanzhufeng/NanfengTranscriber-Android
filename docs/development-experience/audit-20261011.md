## 3. 分类口径

- A 项目专属事实：当前三档、Room v7、现行布局和冻结 APK。
- B 跨项目规则：单一事实、证据分层、资源清理与增量 checkpoint。
- C 明确偏好：一行优先、点击展开、留足冗余；仅作为本项目已确认决策，不自动写长期记忆。
- D 平台约束：Android 前台服务/锁屏/权限/OEM 与进程重要性。
- E 推测：未来云端可用性、真机长时稳定、准确率幅度，均不写成通过结论。

## 6. 项目专属事实与遗留风险

当前三档由 OfficialModelCatalog 定义，任务状态由 TranscriptionTaskState 定义，Room schema 为 v7，简洁岛与详细岛读同一快照。收费调用仅在用户选择并开始时发生；配置、Mock 和实际服务是三层证据。没有把暂停、GPU、波形或 OCR 混入当前完成范围。

尚未验证的遗留风险：真实云端服务/费用、OPPO 长时业务/OEM 原生岛、实际锁续期/系统预算，以及独立人工准确率 A/B。旧设备性能数值只属于原日期、原模型，不能代表当前模型速度或质量。

## 7. 失败经验与防回归资产

- FGS/绑定提升误当 Activity 可见：MainScreenVisibilityPolicy 的回归保留。
- 比例到头就声明完成：TaskNotificationPresentationPolicy / NanfengIslandState 回归保留。
- 详细提示常驻且贴边：IslandDisplayController 回归与真实几何证据保留。
- 用户不点导出也生成外部文件：既有明确导出合同保留。
- 旧模型/Schema/导航正文漂移：新增 [verify_contract_checkpoint.rb](../../scripts/verify_contract_checkpoint.rb) 对照现行所有者，覆盖 Git 跟踪与文档链接，不改产品源码。
