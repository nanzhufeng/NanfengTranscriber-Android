## 2. 版本 15 修复

最终回归发现了一个真实入口分叉：后端已会在加载 Whisper 模型前探测媒体内嵌文字字幕，但主页和 ViewModel 仍在模型未下载时禁用“开始转写”，导致零模型字幕直接提取无法从 UI 进入。

现在的唯一规则为：

- 有选中任务且当前未忙时，可以启动字幕预检，不再由 UI 预先要求模型 `READY`。
- 发现可读内嵌文字字幕时，直接生成带时间轴结果，不加载 Whisper，完成后只进历史。
- 无字幕或字幕不可读时，后端才进入模型检查；模型不存在则转为等待模型，保留任务和中文下一步。
- 新增 `TranscriptionUiStateTest`，覆盖“模型未安装仍可开始字幕预检”和“工作流忙时仍禁止重复启动”。

## 4. 版本 15 模拟器真链路

基准：`1140 × 2616 / 442dpi / font scale 1.0`，只使用 `emulator-5556`；未触碰其他项目的 `emulator-5580`。

- 干净 App 数据、模型状态为“待下载”时，导入 8 秒 MP4 字幕样本。
- 列表内左侧媒体预览、可点圆形选中、参数二次编辑和“开始转写（1）”均可达。
- 无模型直接启动，0.15 秒提取 3 段内嵌字幕，转写列表不保留已完成项，结果直接进历史。
- 历史时间线只显示已完成；视频预览位于白色卡片内左侧，暗陶土橙文字摘要位于右侧。
- 点击卡内媒体进入历史内部“原文件核对”：视频在上，可编辑全文在下，返回仍在历史。
- “复制全部”后粘贴回历史搜索框，得到完整中英文，不是列表省略预览。
- TXT / MD / SRT / DOCX 均经系统保存器真实落盘；大小分别为 108 / 139 / 202 / 1129 bytes。SRT 含 3 个原始时间轴 Cue，DOCX `unzip -t` 通过且 `word/document.xml` 含完整转写文字。
- 同一无模型环境另导入无字幕 WAV；任务可启动，预检后正确留在主页“等待模型”，提示“模型准备好后可继续”。验证后通过 App 删除确认框清理该模拟器测试任务，未删除原媒体、已导出文件或模型。
- 截图证据：`docs/qa/final-regression-v15/`。

## 7. 真机重连后的唯一下一步

1. 只读确认 OPPO 上无运行中转写进程和前台服务。
2. 拉取已安装 APK，将证书 SHA-256 与版本 15 候选包逐项比较；不一致则立即停止。
3. 推送到 `/data/local/tmp`，执行 `pm install -r --user 0`；不用 `adb install`，不卸载，不清数据，不安装测试辅助包。
4. 验证 `firstInstallTime`、模型缓存、历史、皮肤、字幕直接提取、四格式落盘和 crash/ANR。
5. 通过后再开始系统杀进程恢复和 60 分钟/两小时长测；GitHub 继续暂停。
