# 产品简报

## 目标

把 Windows 版南枫转写重建为可长期维护的 Android 正式应用，在不依赖云端转写的前提下完成本地音视频转写，并完整复现核心流程、状态、输出格式与批处理体验。

## 已确认边界

- 复现的是功能、流程、状态和输出格式，不要求 Android 与 Windows 逐字节一致。
- OPPO Find N5 为首要验收设备，最低 Android 10；当前正式包包含 ARM64 与 x86_64，目标设备与隔离模拟器证据分别记录。
- 大多数素材不超过 60 分钟，最长约 2 小时。
- 模型属于 App 私有持久资产：进程退出、重启、同签名覆盖升级后继续使用；卸载时随 App 删除。
- 支持模型导出与导入，避免换机或重装后重复下载。
- UI 继承南枫工作台的低操作成本和南枫记六皮肤体系，但不会机械复制下载器页面。

## 当前模式与证据

- 当前默认为本地标准 SenseVoice；另提供高精度 Qwen Audio 文件转写和低成本 Paraformer 预设，云端模式由用户主动选择并承担对应服务费用。
- 当前能力和未验收项以 [PROJECT_STATUS.md](PROJECT_STATUS.md) 为准；早期 Whisper 候选测试不是当前默认或准确率结论。

## 历史重建阶段门禁

1. 独立工程、领域规则和模型缓存契约可测试。
2. 固定版本的 whisper.cpp JNI 能在模拟器启动、在 Find N5 对真实短样本完成推理。
3. 候选模型在 Find N5 达到可接受速度、内存和温度后，才确定默认模型并扩展完整业务。
4. 完成功能后再做六皮肤、折叠屏适配、长任务和发布验收。
