## 参考来源

唯一入口为 `docs/design-reference-index.md`。禁止直接从南枫下载的旧 `docs/assets`、`reference`、`final-pairs` 或拼合对比板取图。参考顺序必须是：用户当前要求 → 原 Codex 最终确认回合 → 当前安装版 → 权威源码 → 本产品真实数据模型。

## 一级信息架构

一级页面固定为“首页、历史、设置”。模型管理、任务详情、转写结果和导出不是第四个底部入口，而是在对应一级页面内进入详情或动作层。

- 主页：模型就绪状态、未完成队列、批量文件投递、开始、取消、删除和失败/中断恢复。已完成任务和已完成正文禁止出现在主页。模型下载只在设置提供，主页不得重复放置“准备离线模型”按钮。
- 历史：只读取真实已完成记录，按日期/时间线归档；搜索文件名和转写短摘要，不是全文搜索。提供全部时间、今天、近7天、近30天筛选，没有状态/模型筛选入口或历史重试入口。整卡打开可编辑正文/局部复制，编辑先为内存草稿，点击“复制全部”右侧的图标“保存”后持久化，保存中防止重复点击；TXT/Markdown/DOCX导出用草稿，SRT保留原分段。返回只回历史列表，不跳首页。
- 设置：不再显示“隐私与诊断”卡片。首页顶部只显示当前皮肤的单个填充式选框；点击直接打开六套皮肤选择弹窗，每项附由真实皮肤令牌渲染的微型界面预览（页面底、白卡、按钮与导航选中态），选中立即生效并关闭，支持点外部或系统返回取消，不再进入皮肤子页，也不平铺六项。其余为分组菜单：
  - 提醒：灵动岛。
  - 转写与文件：转写模型、调用记录、转写参数、输出与文件；调用记录紧跟转写模型。
  - 关于：关于。
  菜单点击进入独立子页；模型选择、本地缓存和百炼配置整合在“转写模型”页，按所选模型显示。原有删除确认和系统权限入口继续复用。
  设置首页、所有子页和调用记录共用中性浅灰底 `#F0F1F3`、纯白卡片。一级页面所有入口（含当前皮肤）不再叠加灰色承托，入口表面透明、直接融入所属白卡；页面灰底保留。子页与选择弹窗的未选中控件仍为浅灰填充，选中项使用柔和色底和单选标记。菜单不画分隔线。“皮肤、提醒、转写与文件、关于”共用同一张卡外分组标题组件，统一灰色、字号、字重和间距。

内外屏一次只显示一个页面并共用底部纯白悬浮胶囊导航；内屏移除左侧栏，内容获得完整宽度，原双栏/网格仍按窗口适配。几何沿用 2026-10-09 南枫下载：外屏项目高 52dp、内屏 56dp，外屏横向留白 32dp、内屏 24dp，胶囊最大宽 720dp、圆角 32dp、内边距 3dp、选中项圆角 28dp、阴影 0dp；顶部间距 4dp，底部额外间距外屏 4dp/内屏 6dp，系统手势安全区另行保留。内容与导航分别占用根布局空间，导航不能盖住最后一条内容。页面切换立即完成，选中色局部动画 120ms；选中项具备 Tab/已选中语义，切屏不重置根路由。

## 工作台规则

- 主工作区优先占满标题、摘要和固定操作区之外的剩余空间；空状态也保留完整白色工作区骨架。
- 主页的模型/设备摘要保持紧凑，不能挤压文件与转写任务区；高频主操作固定可达。
- 主页结构固定为：标题 → 紧凑运行状态 → 占满剩余高度的转写列表 → 底部投递卡。
- 底部投递卡同时支持系统多文件选择和 Android 文件拖放；两者都使用同一批量入队逻辑。拖放能力受系统/文件管理器多窗口支持限制，多选始终可用。
- 转写列表不得限制只显示前几条；溢出时使用列表内滚动和可见滚动位置。
- 新选文件和可重新开始的任务共用左侧圆形勾选、顶部“全选/取消全选”和列表底部“开始转写（N）”；禁止用“N 个未完成任务”占用全选操作位。
- 任务行稳定展示文件名、时长、模型、语言、进度、更新时间、状态和下一动作；每行左侧必须在行卡内部显示视频缩略图或音频图标，选择勾选叠在预览位上，不得把媒体预览另放到列表外。重试、取消与删除按状态直接可达，低频详情通过展开区域承载。
- 删除任务必须真实删除对应 Room 记录和 App 私有任务文件；运行中先安全停止。不得删除用户原音视频、模型缓存或已经导出的外部文件。
- 成功、失败、等待、取消不只依靠颜色区分。
- 失败、等待文件、等待模型、恢复中和已取消任务保留在主页队列，展示中文原因与真实下一动作。
- UI不以本地模型未下载禁止所有已选任务启动；后端字幕预检先于本地资产检查。任务模型配置和云端Key存在预检仍在字幕探测前；缺少源权限、有效模型配置或云端Key不能据此声称无条件可提字幕。
- 页面切换即时；只对状态变化和展开收起使用克制动画。
- 没有实现的能力不放可点击假按钮。
- 历史读Room真实记录及私有结果；设置参数写DataStore，模型由资产管理器负责，Key由Keystore加密存储，权限按钮打开系统入口；不是所有控件都写DataStore。
- 历史行沿用南枫下载的时间线和整卡操作层级：时间、完成勾和竖线位于卡外左侧；视频缩略图或音频图标固定放在白色结果卡内部左侧，标题、正文摘要、元数据和更多菜单位于右侧。点击媒体预览后在历史页内打开可返回的原文件核对层，播放器下方直接显示同一份可编辑转写文字和“复制全部、保存”及TXT/MD/SRT/DOCX格式导出操作，便于边看边改；不长期复制整段原视频，原文件失效时明确提示重新选择。卡片底部不重复放“复制全部/打开全文”。
- 每条历史记录直接以低饱和、较暗的陶土橙展示正文摘要；整卡打开全文，更多菜单至少包含打开、复制和删除。删除历史时同步删除 App 私有结果，保留用户已导出的文件。
- 模型只对用户提供三档：本地标准 SenseVoiceSmall INT8、高精度 Qwen Audio 文件转写、低成本 Paraformer；新安装默认 `sensevoice-small-int8`。旧 Qwen3 仅兼容已创建任务，不作为新选择展示；Whisper 不在用户模型列表中。模型、语言和 CPU 线程使用纵向选择框。
- 设置首项固定为显示当前皮肤选框的“皮肤”白卡；其余分组白卡以整行点击和末尾方向图标表达进入，不堆叠“进入/查看”等重复文字。设置子页标题居中，左侧使用无横杆ChevronLeft图标（可访问名称“返回设置”），图标返回与系统返回都回到设置菜单，窗口重排保留当前子页，菜单返回保留滚动位置。子页卡片标题下不放重复的装饰性副标题，真实风险、状态、恢复办法和费用边界仍在对应控件附近保留。

## 灵动岛与返回

- 默认简洁版只展示一行图标、阶段和已知百分比；新任务或回到软件后再次退到后台恢复简洁版，进度更新不自行展开。
- 点击简洁版展开详细版，点击标题收起；详细版展示文件、模型、真实已处理/总时长及查看、取消，没有虚假暂停按钮。
- 内屏及横屏沿用状态栏安全区下的原有布局：简洁胶囊最小宽度220dp（空间不足缩小），左右24dp，可见高度34dp、触控至少48dp；展开最大320dp。
- 外屏竖向（窗口宽度小于600dp）改为状态栏顶部居中，保留2dp顶部余量，完整绘制胶囊与展开内容。中央挖孔按系统DisplayCutout范围加左右8dp保护；缺少元数据时保守留出中央56dp。图标/真实阶段在左，已知百分比在右，未知进度右侧仅显示“南枫转写”。简洁宽度随挖孔和字体适配；简洁及展开均为系统图标保留两侧各80dp安全区，不让时钟、信号图标压住文字或卡片轮廓。
- 外屏保留至少48dp触控范围和状态栏下8dp可见边缘；已连接的置顶窗口可直接点击顶部标题展开/收起。内外屏切换、密度/字体/挖孔变化必须触发布局重算，即使进度未变；保留用户当前展开状态，不创建另一份任务事实。
- 状态栏置顶使用用户手动开启的IslandTopmostService及TYPE_ACCESSIBILITY_OVERLAY窗口；与转写服务同在:transcription进程，唯一窗口仍由TaskIslandOverlay管理。无屏幕读取、界面事件订阅、手势或按键过滤能力，不修改其他无障碍服务。服务连接/撤销时移除原窗口再切换宿主和窗口类型，保留当前展开状态；后台每秒检查连接。普通TYPE_APPLICATION_OVERLAY始终使用状态栏下方安全区，不能再把文字放到系统图标下面。主App可见、锁屏时仍按原策略隐藏；不声称高于安全系统窗口。
- “灵动岛”设置在原权限页内提供状态栏置顶、普通悬浮窗、电池策略、通知管理；不新增首页或一级常驻按钮。置顶入口是本轮修复状态栏遮挡所需，点击只打开系统无障碍页，由用户选择“南枫转写灵动岛置顶”；旁边简要披露用途与能力边界，已移除的四段小字说明不恢复。关闭或未授权不影响转写，实际失败信息仍可显示。
- “原文件核对”和“转写结果”右上角使用叉号Close图标，分别具有“关闭原文件核对”“关闭转写结果”可访问名称；沿用原onDismiss及返回历史行为，触控范围和系统返回不变。其他返回入口不因本轮要求改变。
- 关于说明与信息正文统一缩小为11sp（名称14sp）；源码行依据实际字宽和可用宽度向下适配，始终完整单行、不省略，保留链接与可访问点击语义。关于信息保持可选中复制；来源行是“源码与更新：GitHub · nanzhufeng/NanfengTranscriber-Android”，链接用橙色和下划线，点击打开真实仓库。

## 视觉基线

本轮按南枫记 UI 标准统一表面、字阶和几何；南烛枫当前“全软件无边框、无阴影”的明确要求优先于参考标准中的轻阴影。所有一级页、子页及独立详情标题使用共享组件相对几何中线居中；返回为 ChevronLeft，关闭为 Close。

- 六皮肤共用中性浅灰页面底 `#F0F1F3`；内容卡统一纯白 `#FFFFFF`。
- 所有页面的卡片、选项、输入框和弹层取消用于分区的线框；用承载面与控件的明暗差、留白分层；普通内容卡片不绘制阴影轮廓。输入框聚焦也不恢复线框；历史搜索为白色填充，卡内编辑/选择为浅灰填充，选中状态另有标记。菜单、队列、调用记录和详情不画装饰性分隔线。底部导航、按钮、拖放区、状态提示、后台悬浮岛、下拉菜单和应用弹窗同样为零阴影，不以暗边替代线框；菜单与弹窗走共享组件。
- 绿色、紫色、橙色和土色只用于模块标题、图标、状态和选中反馈，不给整张卡染色。
- 选中导航使用完整浅色容器、图标和文字共同表达，不只改变文字色。
- 图标使用真实 Material/品牌资源，不使用 Emoji 或临时字符代替。

## 六皮肤

共享尺寸、排版、语义色和状态组件，仅替换小面积强调与选中反馈；当前所有皮肤均保持零边框、零阴影。默认提供清晰、低饱和、纯白卡片的工作台基线，最终六套名称和细节以南枫记正式设计系统为准。

## 验收视口

- Find N5 外屏：`1140 × 2616`、`442 dpi`、font scale `1.0`，主页/历史/设置各一张独立截图。
- Find N5 内屏：`2248 × 2480`，首页/历史/设置各一张独立截图，用于验证底部悬浮导航和空间重排。
- 模拟器可用于开发回归，但不能替代上述真机六页证据；拼图不能充当实现规格。

## 图标

唯一母版位于 `branding/app_icon_master.png`。Android 密度资源只做等比例缩小，不裁切、不拉伸、不重绘、不改色，也不为圆形图标另加底板；`icon` 与 `roundIcon` 使用同一母版派生资源。由启动器执行系统遮罩造成的外观差异必须在 Find N5 桌面截图中单独验收。
