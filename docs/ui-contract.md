# UI 契约

## 参考来源

唯一入口为 `docs/design-reference-index.md`。禁止直接从南枫下载的旧 `docs/assets`、`reference`、`final-pairs` 或拼合对比板取图。参考顺序必须是：用户当前要求 → 原 Codex 最终确认回合 → 当前安装版 → 权威源码 → 本产品真实数据模型。

## 一级信息架构

一级页面固定为“主页、历史、设置”。模型管理、任务详情、转写结果和导出不是第四个底部入口，而是在对应一级页面内进入详情或动作层。

- 主页：模型就绪状态、未完成队列、批量文件投递、开始、取消、删除和失败/中断恢复。已完成任务和已完成正文禁止出现在主页。模型下载只在设置提供，主页不得重复放置“准备离线模型”按钮。
- 历史：只读取真实的已完成记录，按日期和时间线归档；支持按文件名或转写文字搜索，并提供全部时间、今天、近 7 天、近 30 天筛选。点击整卡进入历史内部二级结果层，完整正文以可编辑多行输入框呈现，可局部选择和复制。TXT/Markdown/DOCX 导出使用编辑后文字，SRT 保留原始时间轴分段。返回只回历史列表，不允许跳到主页。
- 设置：模型与存储、语言/线程等转写参数、皮肤与显示、隐私、诊断和关于。

外屏一次只显示一个页面并使用底部导航；内屏一次只显示一个页面并使用左侧导航。每页根视口、安全区、导航高度和滚动边界一致，不能把三个页面同时塞进一个画面。

## 工作台规则

- 主工作区优先占满标题、摘要和固定操作区之外的剩余空间；空状态也保留完整白色工作区骨架。
- 主页的模型/设备摘要保持紧凑，不能挤压文件与转写任务区；高频主操作固定可达。
- 主页结构固定为：标题 → 紧凑运行状态 → 占满剩余高度的转写列表 → 底部投递卡。
- 底部投递卡同时支持系统多文件选择和 Android 文件拖放；两者都使用同一批量入队逻辑。拖放能力受系统/文件管理器多窗口支持限制，多选始终可用。
- 转写列表不得限制只显示前几条；溢出时使用列表内滚动和可见滚动位置。
- 新选文件和可重新开始的任务共用左侧圆形勾选、顶部“全选/取消全选”和列表底部“开始转写（N）”；禁止用“N 个未完成任务”占用全选操作位。
- 任务行稳定展示文件名、时长、模型、语言、进度、更新时间、状态和下一动作；每行左侧必须在行卡内部显示视频缩略图或音频图标，选择勾选叠在预览位上，不得把媒体预览另放到列表外。重试、取消与删除按状态直接可达，低频详情通过展开区域承载。
- 删除任务必须真实删除对应 Room 记录和 App 私有任务文件；运行中先安全停止。不得删除用户原音视频、模型缓存或已经导出的外部文件。
- 成功、失败、等待、取消不只依靠颜色区分。
- 失败、等待文件、等待模型、恢复中和已取消任务保留在主页队列，展示中文原因与真实下一动作。
- 模型未准备时不得在 UI 层禁止所有已选任务启动：用户可先开始媒体内嵌字幕预检。只有后端确认无可读字幕后才进入模型门禁；模型不存在时任务留在主页等待模型，不丢失选择和冻结参数。
- 页面切换即时；只对状态变化和展开收起使用克制动画。
- 没有实现的能力不放可点击假按钮。
- 历史只读 Room 的真实记录；设置控件必须写入真实 DataStore/模型存储状态。
- 历史行沿用南枫下载的时间线和整卡操作层级：时间、完成勾和竖线位于卡外左侧；视频缩略图或音频图标固定放在白色结果卡内部左侧，标题、正文摘要、元数据和更多菜单位于右侧。点击媒体预览后在历史页内打开可返回的原文件核对层，播放器下方直接显示同一份可编辑转写文字和“复制全部、TXT、MD、SRT、DOCX”操作，便于边看边改；不长期复制整段原视频，原文件失效时明确提示重新选择。卡片底部不重复放“复制全部/打开全文”。
- 每条历史记录直接以低饱和、较暗的陶土橙展示正文摘要；整卡打开全文，更多菜单至少包含打开、复制和删除。删除历史时同步删除 App 私有结果，保留用户已导出的文件。
- 模型只对用户提供三档：极速 Base、均衡 Small Q5_1、高质量 Large V3 Turbo Q5_0；新安装默认均衡档。模型、语言和 CPU 线程均使用纵向选择框，不使用横向滑动胶囊。
- 设置首项固定为“皮肤”；设置卡片标题下不放重复的装饰性副标题，真实风险、状态、恢复办法和费用边界仍在对应控件附近保留。

## 视觉基线

- 页面底为较深、低饱和的灰绿；内容卡统一纯白 `#FFFFFF`。
- Material 卡片显式关闭 tonal overlay，使用中性细描边和极轻阴影。
- 绿色、紫色、橙色和土色只用于模块标题、图标、状态和选中反馈，不给整张卡染色。
- 选中导航使用完整浅色容器、图标和文字共同表达，不只改变文字色。
- 图标使用真实 Material/品牌资源，不使用 Emoji 或临时字符代替。

## 六皮肤

共享尺寸、排版、语义色和状态组件，仅替换颜色、材质、阴影与有限装饰 token。默认提供清晰、低饱和、纯白卡片的工作台基线，最终六套名称和细节以南枫记正式设计系统为准。

## 验收视口

- Find N5 外屏：`1140 × 2616`、`442 dpi`、font scale `1.0`，主页/历史/设置各一张独立截图。
- Find N5 内屏：`2248 × 2480`，主页/历史/设置各一张独立截图，用于验证左侧导航和空间重排。
- 模拟器可用于开发回归，但不能替代上述真机六页证据；拼图不能充当实现规格。

## 图标

唯一母版位于 `branding/app_icon_master.png`。Android 密度资源只做等比例缩小，不裁切、不拉伸、不重绘、不改色，也不为圆形图标另加底板；`icon` 与 `roundIcon` 使用同一母版派生资源。由启动器执行系统遮罩造成的外观差异必须在 Find N5 桌面截图中单独验收。
