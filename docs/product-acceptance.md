## 1. 第一用户任务

- 用户目标：批量导入本地音视频，离开 App 后继续本地转写，在历史中对照原视频编辑、复制和导出文字。
- 真实输入：单个/多个音视频、其他 App 分享；有内嵌文字字幕时优先直接提取。
- 最终结果：已完成任务只进历史，完整文字可编辑/局部复制/全部复制，TXT、MD、SRT、DOCX 可真实保存。
- 当前实现还包括用户主动选择的云端文件转写预设，真实服务是否可用另行验收。不属于当前实现：画面硬字幕 OCR、外挂字幕自动关联、GPU 推理、转写暂停/波形/摘要。

## 2. 核心概念与唯一所有者

| 概念 | 唯一所有者 | 禁止分叉 |
| --- | --- | --- |
| 本地模型资产 | `ModelAssetManager` + `FileModelStore` | 仅 SenseVoice/Whisper 使用；UI 不自行判定文件可用，不重复下载 |
| 新云端模型 | `DashScopeFileTranscriptionClient` + `DashScopeFileTranscriptionEngine` | Qwen Audio 文件转写与 Paraformer；旧 Qwen3 只兼容旧任务，不伪装本地或后处理 |
| 转写任务真相 | Room v7 | 主页和历史不保存平行状态 |
| 后台执行 | `TranscriptionForegroundService` + `:transcription` | WorkManager 不承担两小时主任务 |
| 字幕与 ASR 路由 | 后端 runner | UI 不在字幕预检前强制要求模型 |
| 完整结果 | App 私有 JSON/TXT | 外部导出失败不得删除历史真相 |
| 后台提醒 | `NanfengIslandState` / `TaskProgressUpdateGate` | 通知、悬浮窗同一进度事实 |
| 提醒模式 | `IslandDisplayController` | 默认简洁，点击展开/收起，不随进度自行展开 |

## 3. 状态与操作

| 状态 | 事实条件 | 中文下一步 | 持久化/恢复 |
| --- | --- | --- | --- |
| 等待 | 输入、模型或系统恢复条件未满足 | 重新选择、准备模型或重试 | Room 保留任务和冻结参数 |
| 字幕预检 | 文件/任务配置预检已通过，云端还需Key存在 | 无需本地模型文件；不是绕过云端Key/有效模型配置 | 命中字幕直接保存分段 |
| 运行 | 解码、模型加载、转写或私有保存 | 通知/灵动岛展示真实阶段与取消入口 | 按当前模型分块提交；SenseVoice 推荐 30 秒 |
| 完成 | 存在可读分段且私有结果已落盘 | 只在历史查看/导出 | Room + 私有结果文件 |
| 失败/无语音 | 有明确原因或无可读文字 | 显示原因、重试或删除 | 留在主页，不伪装成历史完成 |

## 4. 性能、缓存与诊断

- 模型写入 `noBackupFilesDir`，长度/SHA-256 校验、断点续传、原子提交；同签名覆盖不重下。
- 相邻同模型+同线程任务复用队列级内存会话，磁盘缓存与热会话职责分开。
- 历史版本 14 Find N5 的 87 秒样本：解码 2.87 秒、模型加载 0.66 秒、转写 181.12 秒、实时系数 2.07；只对应旧模型/旧版本，不能外推当前 SenseVoice 或云端速度。
- 原始自动化报告位于 `app/build/reports/`和 `app/build/test-results/`；图形证据位于 `docs/qa/`。

## 5. 账号、权限与费用

- SenseVoice 与 Whisper 是本地转写：无登录、无 API Key、音视频不上传。
- 新高精度 Qwen Audio 文件转写与低成本 Paraformer 沿用百炼 API Key；旧 Qwen3 只保留已创建任务兼容。用户主动选择云端并开始才外发音频，临时上传和潜在费用在模型配置区域说明。Keystore AES-GCM 保存凭据，不进备份、日志、Git；未配置 Key 不允许提交收费任务。
- 用户拒绝通知或文件权限时必须有可恢复中文提示；不得用卸载/清数据作为解决方案。

现行实现限制按 [领域规则](domain-rules.md) 验收：正文保存后重开可读，自动导出按任务快照只尝试一次、历史仅文件名/短摘要搜索、SAF直接写所选目录、SKIP没有新写入、取消云端不等于远端撤销。不得在不改源码的合同整理中声称已实现全文检索、跨重启编辑、远端免费取消或跨介质事务。
