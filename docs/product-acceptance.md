# 南枫转写 Android 功能与真实验收合同

日期：2026-07-21

状态：版本 15 已实现，自动与模拟器验收通过，最终 Find N5 发布门禁未全通过

## 1. 第一用户任务

- 用户目标：批量导入本地音视频，离开 App 后继续本地转写，在历史中对照原视频编辑、复制和导出文字。
- 真实输入：单个/多个音视频、文件夹、其他 App 分享；有内嵌文字字幕时优先直接提取。
- 最终结果：已完成任务只进历史，完整文字可编辑/局部复制/全部复制，TXT、MD、SRT、DOCX 可真实保存。
- 不属于当前完成范围：画面硬字幕 OCR、外挂字幕自动关联、GPU 推理、云端音视频转写。

## 2. 核心概念与唯一所有者

| 概念 | 唯一所有者 | 禁止分叉 |
| --- | --- | --- |
| 模型磁盘资产 | `ModelAssetManager` + `FileModelStore` | UI 不自行判定文件可用，不重复下载 |
| 转写任务真相 | Room v4 | 主页和历史不保存平行状态 |
| 后台执行 | `TranscriptionForegroundService` + `:transcription` | WorkManager 不承担两小时主任务 |
| 字幕与 ASR 路由 | 后端 runner | UI 不在字幕预检前强制要求模型 |
| 完整结果 | App 私有 JSON/TXT | 外部导出失败不得删除历史真相 |

## 3. 状态与操作

| 状态 | 事实条件 | 中文下一步 | 持久化/恢复 |
| --- | --- | --- | --- |
| 等待 | 输入、模型或系统恢复条件未满足 | 重新选择、准备模型或重试 | Room 保留任务和冻结参数 |
| 字幕预检 | 任务已启动，尚未判断文字轨 | 无需模型也可执行 | 命中字幕直接保存分段 |
| 运行 | 解码、模型加载、转写或导出 | 通知展示真实阶段和停止入口 | 约 5 分钟分块原子提交 |
| 完成 | 存在可读分段且私有结果已落盘 | 只在历史查看/导出 | Room + 私有结果文件 |
| 失败/无语音 | 有明确原因或无可读文字 | 显示原因、重试或删除 | 留在主页，不伪装成历史完成 |

## 4. 性能、缓存与诊断

- 模型写入 `noBackupFilesDir`，长度/SHA-256 校验、断点续传、原子提交；同签名覆盖不重下。
- 相邻同模型+同线程任务复用队列级内存会话，磁盘缓存与热会话职责分开。
- 版本 14 Find N5 的 87 秒高质量样本：解码 2.87 秒、模型加载 0.66 秒、转写 181.12 秒、实时系数 2.07；这一档当前不符合“高速”。
- 原始自动化报告位于 `app/build/reports/`和 `app/build/test-results/`；图形证据位于 `docs/qa/`。

## 5. 账号、权限与费用

- 本地转写无登录、无 API Key、音视频不上传。
- 兼容文字润色默认关闭；只有用户主动配置时才发送转写文字，API Key 用 Keystore AES-GCM 加密且不进备份。
- 用户拒绝通知或文件权限时必须有可恢复中文提示；不得用卸载/清数据作为解决方案。

## 8. 反馈—原因—实现—验证

| 用户反馈 | 根因 | 唯一实现 | 验证 | 尚存风险 |
| --- | --- | --- | --- | --- |
| 主页不要出现已完成 | 页面所有权混用 | Room 状态过滤，完成即离开主页 | 字幕样本完成后主页为空、历史有且仅有完成记录 | 长队列还需真机批量回归 |
| 视频必须在列表卡内左侧 | 早期媒体槽位放在卡外 | 主页/历史共用卡内媒体槽位 | 版本 15 模拟器和版本 14 OPPO 截图 | 原文件失效恢复还需更多真机样本 |
| 视频下方可编辑文字 | 结果弹层只读 | 历史内原文件核对层 + EditText | 复制全部完整粘贴，四格式真实落盘 | 编辑后是否持久为新真相需单独产品决策 |
| 有字幕的视频直接识别文字 | UI 早于后端检查模型 | runner 先字幕探测，UI 不再前置模型门禁 | 无模型 8 秒 MP4、3 Cue、0.15 秒提取 | 硬字幕 OCR 和外挂字幕未实现 |
