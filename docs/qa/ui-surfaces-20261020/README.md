## 最终界面合同

- 全软件中性浅灰底 `#F0F1F3`、纯白内容卡、浅灰输入/选择面；六皮肤只改变小面积强调和选中反馈。
- 内容卡、按钮、底栏、状态提示、拖放区、后台悬浮岛、下拉菜单及模态卡均不画边框或阴影；不以分隔线代替表面层级。图标、单选标记、时间线及进度线仍表达本来语义。
- 首页、历史、设置、各子页、原文件核对和结果页使用共享居中标题；返回为 ChevronLeft、关闭为 Close。单行操作为胶囊；输入和选项为同轮廓的填充面。
- 设置仅显示当前皮肤选框，点击弹窗选六套皮肤，立即生效并关闭；每个选项附真实皮肤令牌的微型界面预览；支持外部和系统返回取消，避免六项常驻平铺。分组标题统一灰色、卡外位置、字号、字重与间距。调用记录紧跟转写模型；“信息”分组改为“关于”。
- 列表、记录空态、API Key、参数、搜索、正文编辑及详情统一承载层级；业务、持久化、模型/权限/导出回调保留。
