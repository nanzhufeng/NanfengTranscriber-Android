# 2026-10-09 导航验收

目标包：南枫转写 `0.14.6 (21)` 正式 Release。参考南枫下载权威源码 `PrimaryFloatingNavigation` 的 2026-10-09 底部胶囊实现；来源见 `../../design-reference-index.md`。

隔离模拟器 `emulator-5592`：外屏 1140×2616、内屏 2248×2480，442dpi、font scale 1.0。首页/历史/设置各有独立 PNG 和 UI XML。`contact-sheet.jpg` 仅是验收联系表，不是软件同屏布局。

`verify_navigation.rb` 读取真实导航节点后点击并断言选中、共享底部位置、52/56dp 项目高度、720dp 最大宽度；外屏设置切为内屏仍选中设置。结果见 `acceptance.txt`。该脚本只允许固定隔离模拟器，不调用仪器测试；退出时恢复原分辨率与密度。

人工检查联系表：内外屏均为纯白底部胶囊，圆角选中态和阴影轮廓一致，无内屏左侧导航；系统手势条留在导航下方。保留既有单双栏内容适配和当前皮肤强调色。

80 项 JVM 单测、lint、正式签名构建通过。实际 OPPO 未连接，未替用户执行主设备覆盖或业务操作；模拟器尺寸/配置切换不等于真实折叠硬件验收。
