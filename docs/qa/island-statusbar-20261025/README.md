## 结果

- 外屏竖向（宽度小于600dp）窗口顶部居中，2dp顶部留量保证完整轮廓；左侧图标/实际阶段、右侧已知百分比，未知百分比显示软件名，不伪造进度。中央摄像头范围两侧各加8dp保护；系统没有报告挖孔时保守预留中央56dp再加保护量。
- 外屏简洁胶囊按字体和挖孔宽度适配；简洁/展开窗口均在两侧系统图标区域之外（各80dp）完整呈现，不用增加权限强压系统层。保留至少48dp触控区域及状态栏下8dp可见边缘用于展开/收起；系统状态栏内的触摸归SystemUI，第一次直接点击状态栏内容未展开的现象已实际观察并据此调整。
- 内屏/横屏沿用原安全区布局和单行标题，展开最大320dp。屏幕尺寸、密度、字体、状态栏或挖孔改变时重绘，即使任务进度未变也不会跳过；原显示模式由IslandDisplayController保持。
- 胶囊和展开卡片无描边、无阴影；保留原查看/取消回调和主App可见/锁屏时隐藏的时机。未改变转写、通知数据或任务状态。
