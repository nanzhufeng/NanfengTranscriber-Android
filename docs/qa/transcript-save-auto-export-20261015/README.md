# 正文保存与按选中格式自动导出

2026-10-15，WORKTREE，版本号未递增；Debug开发验证，正式0.14.8冻结包未改。用户截图为南枫转写原文件核对页，非南枫下载。

## 实现

- 原文件核对与全文页共用编辑器；“复制全部”右侧增加Save图标及保存按钮。明确点击后临时替换私有结果，重开读取修订正文，历史摘要同步更新；保存期间不重复提交或继续修改。保留原字幕时间轴、语言及诊断，SRT仍使用原分段。
- 新建任务把结果页下拉框记住的lastExportFormat、默认目录和重名策略写入既有Room字段。后台runner保存私有结果后自动导出一次，无需进入结果页；无目录/导出失败保留私有结果并提示手动导出。
- AutomaticExportOnce以任务目录持久凭据先占位后外部写入。重开/恢复不自动再次创建副本；中断结果未知时需检查目录后手动导出。不是SAF与Room的跨介质事务，也不保证被系统突然终止时外部文件完整。
- 待开始来源的格式摘要跟随同一设置；手动导出区分Written/Skipped，跳过不声称新写入。已有完成历史不补自动导出。
- JSON是修订真相；初始私有TXT便捷副本不是自动导出到用户目录的文件，修订后的复制/摘要/文本导出均读取JSON。旧TXT结果也可临时替换保存。
