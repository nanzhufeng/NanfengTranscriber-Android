# 决策记录

## 2026-07-20：独立原生 Android 重建

选择 Kotlin、Compose、Room 和 C++ JNI，不封装 Windows Python/PySide6。原因是 Android 生命周期、后台限制、模型内存、SAF 和折叠屏体验都需要原生控制。

## 2026-07-20：先过推理门禁，再完成 UI

默认模型必须由 OPPO Find N5 的真实速度、峰值内存、温度和稳定性决定。候选包含 base、small、medium 量化与 large-v3-turbo 量化，不在桌面基准上提前指定。

## 2026-07-20：模型放入 no-backup 私有目录

模型需要覆盖升级后长期存在，但不适合 Android 云备份；因此使用 `noBackupFilesDir`，同时提供 SAF 导入导出。

## 2026-07-20：六皮肤共享同一页面树

六套皮肤只改变设计 token、材质与有限装饰，不复制业务页面和状态逻辑。

## 2026-07-20：固定 whisper.cpp v1.9.1

原生推理依赖固定为官方 `v1.9.1`、提交 `f049fff95a089aa9969deb009cdd4892b3e74916`，以 Git submodule 记录来源。首个门禁使用通用 Android CPU 后端，ARM 特定加速必须经过兼容性与性能实测后再开启。

## 2026-07-20：候选模型清单先校验、不预设赢家

候选为 Base、Small Q5_1、Medium Q5_0、Large V3 Turbo Q5_0。字节数和 SHA-256 来自官方 Hugging Face LFS 响应头，下载 URL 固定到仓库修订 `5359861c739e955e79d9a303bcbc70fb988958b1`，记录在 `OfficialModelCatalog`。在 Find N5 真实基准前不指定正式默认模型；目录顺序只表示测试顺序。

## 2026-07-20：正式签名兼顾安全与跨平台交接

南枫转写使用独立 RSA-4096 正式签名。主 keystore 放在仓库外，密钥文件备份到 iCloud Drive，密码保存于 macOS 钥匙串；Gradle 同时支持环境变量和用户级 Gradle 属性，方便 Windows、CI 或其他开发环境一次配置后长期复用。仓库只提供不含秘密的一键复制脚本，不保存明文密码。

## 2026-07-20：南枫下载参考必须经过 Codex 权威链路

“参考南枫下载”不能等同于搜索同名目录或打开 `docs/assets`。最终顺序固定为：本轮用户要求 → 原 Codex 最终确认回合 → 当前 OPPO 安装版 → 权威持续开发源码 → 带版本的独立截图。旧 `find-n5-home-*`、`reference`、`reference-normalized`、`final-pairs` 和拼合对比板只保留为过程证据，不得驱动实现。项目入口记录在 `docs/design-reference-index.md`。

## 2026-07-20：长转写使用直接前台服务，不由 WorkManager 承担

用户素材最长约两小时，需要离开 App 后继续执行、通知栏显示真实进度并可取消。Android 16 上长时间 WorkManager 任务会占用 JobScheduler 配额，因此转写由直接前台服务持有；Android 15/API 35 使用 `mediaProcessing` 类型，旧系统使用覆盖本地文件处理的 `dataSync` 类型。系统强制停止 App 仍会终止任务，这是 Android 平台边界；用户重新打开 App 后由 Room 恢复未完成任务。

## 2026-07-20：原生推理放入独立进程

whisper.cpp 模型内存和原生崩溃不应拖垮主页、历史与设置 UI。转写服务固定运行在 `:transcription` 进程，使用 Room 多进程失效通知同步状态；完成、取消和系统超时后终止该进程释放模型内存。系统杀死服务进程时，`START_REDELIVER_INTENT` 与 Room 的恢复状态共同保证同一任务可重新执行，而不是静默丢失。

## 2026-07-20：任务参数与完整结果都持久化

Room v2 将线程数冻结到任务，避免后台进程依赖 DataStore 的瞬时读取；v1→v2 使用显式迁移并保留既有记录。完成结果先原子写入 `transcript.json`，再写便捷 TXT，历史页从 JSON 打开完整内容并可重新导出 TXT、Markdown、SRT 和 DOCX。

## 2026-07-20：长素材每 5 分钟提交可恢复断点

Find N5 的 60 分钟重复语音压力样本在约 77% 时被 ColorOS/系统以 `OTHER KILLS BY SYSTEM` 终止，退出时 RSS 约 525 MB；旧实现虽然能重新启动任务，但会删除 PCM 并从头执行，不能满足低成本长转写。版本 7 改为解码完成即保存 PCM 元数据，每个 5 分钟分块完成后原子提交累计分段、绝对时间戳、已处理样本和性能数据。恢复时只有源、模型、语言、线程和 PCM 长度完全匹配才复用，最多重做当前未提交分块；成功后再清理 PCM 和断点。该方案不要求用户手动配置 ColorOS 白名单，也不把系统杀进程误报为完成。

## 2026-07-21：队列级热会话以模型和线程为复用键

批量任务由 `QueueModelSessionOwner` 持有唯一推理会话。相邻任务的模型和线程相同则直接热复用；任一参数变化才释放旧会话并加载新模型，整批队列结束后统一释放。磁盘模型仍由 `ModelAssetManager` 长期缓存，两层缓存职责不混用。

## 2026-07-21：无语音不是历史完成记录

只有包含可读分段的结果才能进入 `COMPLETED`。空白、纯占位或没有识别文字的结果进入 `NO_SPEECH`，继续留在主页，显示中文原因并允许重新选择模型或语言后重试，历史页始终只承接真实完成结果。

## 2026-07-21：用户目录自动导出建立在私有真相文件之后

Room v3 为每项任务冻结输出目录 URI、格式和冲突策略。转写完成时先原子保存 App 私有 JSON/TXT，再由 `AndroidTranscriptOutputStore` 写入用户选定的 SAF 目录。外部目录权限失效或导出失败只报告可恢复错误，不删除私有结果；默认同名策略为自动重命名。

## 2026-09-11：用户目录导出改为明确操作

自动导出会让用户在没有点按导出时看到 TXT，违背导出操作的真实语义。任务完成现在只保存 App 私有 JSON/TXT 与历史记录；默认输出目录仅为结果页用户明确点按“导出”时提供目标位置。旧任务即使保留过期目录 URI，也不会再触发外部写入。

## 2026-07-21：六套南枫皮肤共享一棵业务页面树

正式提供玄岩浮影、青林木语、枫绯凝霜、绛绡叠韵、铜棕弦影和青玉流岚。皮肤只替换背景、卡片、强调色、正文色和完整选中态 token，不复制主页、历史和设置页面；选择写入 DataStore，强制关闭和同签名覆盖后仍应保留。

## 2026-07-21：移动端推理后端只展示已验证能力

Find N5 尚未完成 GPU 兼容性、速度和温控门禁，因此设置页明确显示“CPU 稳定模式”，不提供没有真实效果的 GPU 开关。后续只有在相同素材的稳定性、峰值内存和温度均通过后才增加可选加速后端。

## 2026-07-21：旧兼容文字后处理记录（已废止）

旧版本曾支持可配置的转写后文字 API。2026-08-30 起，该产品路径已废止：旧 Room 字段仅为读取历史任务保留，运行时不再执行，设置页也不再展示地址、自由模型名或该开关。

## 2026-08-30：模型是转写选择，不是后处理链

用户可见模型固定为本地标准 SenseVoiceSmall INT8 + sherpa-onnx 与高精度 Qwen3-ASR API；Whisper 不再出现在任何用户选择面。Qwen 在引擎工厂中作为 `SpeechEngine` 直接转写音频分段；旧文字润色执行路径已停用，旧字段只用于兼容读取历史任务。设置页不展示地址/自由模型输入，模型单选切换立即生效；Qwen 的音频外发与潜在费用固定可见，API Key 仅用 Android Keystore 保存。

## 2026-08-30：云端调用账本以完整源文件为粒度

Qwen 的后台执行可以继续按音频分段以控制长文件和失败恢复，但调用记录不得把内部片段暴露成用户账本。协调器仅聚合安全的分段次数、已送出音频时长和服务端 Token；任务成功或最终失败时才写一条文件级事实，UI 按任务文件合并重试。费用沿用南枫 AI 的版本化本机估算原则：固定中国区 Qwen3-ASR-Flash 的公开音频时长单价、以人民币微元保存价格版本/币种/估算值；未送出音频、免费额度、活动优惠和服务端最终结算均不伪造成确定扣费。

## 2026-07-21：字幕预检先于模型门禁

“开始转写”的 UI 资格只由是否有选中任务、工作流是否忙决定，不再要求语音模型已安装。执行器先探测容器文字轨；命中可读字幕则直接完成，未命中才检查模型并转为可恢复的等待模型状态。这一顺序同时避免不必要下载和“后端有能力、前端不让用”的入口分叉。
